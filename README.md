# Portfolio GitHub Foundations

Projeto desenvolvido para aplicar na prática os conhecimentos adquiridos durante a trilha **GitHub Foundations**.

## Objetivo

Este repositório tem como objetivo demonstrar conceitos de versionamento de código utilizando Git e GitHub.

Durante o desenvolvimento serão aplicados conceitos como:

- Repositórios Git
- Commits
- Branches
- Pull Requests
- Merge
- Versionamento de código

## Tecnologias

- HTML
- CSS
- JavaScript
- Git
- GitHub
